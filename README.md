# Пример работы с git-репозиторием

Основные команды:
```
git add .
```
* сохранить текущее состояние файлов
```
git commit - m "что сделано?"
```
* отправить сохранения на гит
```
git push origin <ветки>
```
* подтянуть с гита файлы .gitignore и README
```
git pull origin <ветка>
```

**Разработка**

* создать ветку:
```
git branch dev
```

* перейти в ветку:
```
git checkout dev
```

* создать ветку и сразу перейти в нее:
```
git checkout -b dev
```

* сохранить текущее состояние репозитория
```
git add .
git commit -m "что сделал"
```

* выгрузка на гит
```
git push origin <ветка>
```
